## Lab Questions

### What is difference between edge and level sensitive circuits?
For a scenario where Q is dependent on the Value of input D, an edge circuit allows D to change the value of Q only when the clock is rising or falling from 0-1. For a level circuit, whenever the clock value is equal to 1, D can alter Q's value. 
### Why is it important to declare initial state?
Because when an initial state is declared, our circuit has safe and predictable behavior. 
### What do edge sensitive circuits let us build?
Many things including timers/counters, as well as Jk flipflop, D flipflop, and t flipflop memory circuits which are the foundation for how we can save memory on computers.
